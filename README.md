# SehatNxt Desktop for Windows

Downloads of the SehatNxt hospital app for Windows, with offline emergency mode (the billing PC keeps
billing and prescriptions working over the hospital Wi-Fi when the internet is down).

**Download the latest version:**
https://github.com/sehatnxt/sehatnxt-desktop/releases/latest/download/SehatNxt-Setup-x64.exe

- Run the file on the PC. No admin rights are needed; it installs for the current Windows user.
- Installed apps update themselves: a new version downloads in the background and installs the next time
  SehatNxt is closed.
- Every version is listed under [Releases](https://github.com/sehatnxt/sehatnxt-desktop/releases).

This repository holds the setup files only. Help: contact@sehatnxt.com · https://sehatnxt.in
